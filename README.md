# Simple AI Agent Tool Selection

This example demonstrates a basic AI agent capable of understanding a request and selecting an appropriate 'tool' (function) to fulfill it. It simulates the core agent loop of perceiving input, making a decision, and executing an action. This concept is fundamental to frameworks like DeerFlow, which enable more complex autonomous agents.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
